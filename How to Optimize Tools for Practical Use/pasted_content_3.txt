ABSOLUTE ARCHITECTURAL RULES
━━━━━━━━━━━━━━━━━━━━

1. EVENT-DRIVEN EVERYTHING

* No direct module coupling.
* All state changes emit typed events.
* Every subsystem communicates through the EventBus.
* Event history must be inspectable and replayable.

2. RUNTIMEMANAGER IS THE SINGLE SOURCE OF EXECUTION TRUTH

* No subprocess spawning outside RuntimeManager.
* No plugin execution outside RuntimeManager.
* No hidden execution paths.
* RuntimeManager owns:

  * venv lifecycle
  * subprocess orchestration
  * dependency installs
  * sandboxing
  * snapshots
  * cancellation
  * rollback
  * process supervision
  * execution metadata

3. DAG FIRST, AI SECOND

* Prioritize deterministic graph execution.
* Prioritize reproducible workflows.
* Prioritize visual execution graphs.
* AI augments execution.
* AI never bypasses runtime validation.

4. AGENTS ARE ORCHESTRATORS
   Agents must NOT:

* recursively self-prompt
* recursively spawn agents
* autonomously rewrite runtime state
* execute arbitrary unsafe code

Agents SHOULD:

* consume structured events
* produce deterministic plans
* request validated runtime actions
* recommend repairs
* analyze failures
* propose dependency resolutions

5. UI IS VISUALIZATION ONLY
   UI must:

* render runtime state
* render logs
* render graphs
* dispatch commands
* visualize agents
* visualize execution state

UI must NOT:

* own runtime logic
* directly execute subprocesses
* directly mutate internal runtime state

6. PLUGINS MUST BE ISOLATED
   Every plugin requires:

* manifest definition
* capability declaration
* sandbox boundaries
* scoped permissions
* dependency isolation
* runtime validation

7. WINDOWS-FIRST STABILITY
   The platform must:

* work natively on Windows 11
* support PyInstaller packaging
* support graceful teardown
* support process cancellation
* support dark mode
* avoid Electron entirely
* avoid cloud dependency requirements
